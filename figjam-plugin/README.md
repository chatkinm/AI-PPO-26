# FigJam Plugin: Xpage ППО Sync

Плагин для **100% автоматической отрисовки структуры проекта и экранов** на холсте FigJam прямо из локального AI-сервиса ППО без ручных манипуляций и `Ctrl+V`.

---

## 🚀 Как запустить за 2 шага:

### Шаг 1: Подключить манифест в FigJam (делается 1 раз)
1. Откройте любой холст FigJam (в браузере или в приложении Figma) или перейдите по ссылке: [figma.com/board/new](https://www.figma.com/board/new).
2. Нажмите на иконку меню в левом верхнем углу (логотип Figma) ⟶ **Plugins** ⟶ **Development** ⟶ **Import plugin from manifest...**.
3. Выберите файл:
   `figjam-plugin/manifest.json`
4. Плагин **"Xpage ППО FigJam Sync"** мгновенно появится в вашем списке плагинов!

### Шаг 2: Нарисовать структуру на холсте в 1 клик
1. Нажмите в меню **Plugins ⟶ Development ⟶ Xpage ППО FigJam Sync** (или `Ctrl + /` ⟶ введите `Xpage`).
2. В появившемся окне выберите проект (плагин сам подключится к `http://127.0.0.1:8080`).
3. Нажмите кнопку **"⚡ Нарисовать на холсте FigJam"**.
4. За 0.5 секунды плагин автоматически:
   - Создает центральный узел проекта;
   - Создает блоки модулей;
   - Создает карточки экранов с отметками строк сметы;
   - Создает стикеры интерфейсных элементов;
   - Соединяет все уровни векторными стрелками (`Connectors`);
   - Центрирует экран на готовой карте!

---

## 🔒 Безопасность и архитектура
- Плагин выполняет запросы только к вашему локальному контуру `http://127.0.0.1:8080`.
- Никакие клиентские данные не покидают ваш закрытый периметр.
